# Synthetic scenario policy

Every case is independently authored from the task requirements, using fictional organizations, roles, notes, budgets, prices, receipts and constraints. All load-bearing facts are included in that case's executor input. No real private data, current external factual claim, or historical project execution evidence is required. The values are not estimates of actual markets or customers.

Scenario judgments apply the supplied task objective and frozen Blitz operating/company rules: distinguish facts and unknowns; infer only what the evidence supports; prepare the requested useful result; preserve existing authority and privacy boundaries; use proportionate evidence; distinguish user, buyer and resource authority; avoid conflating intent, contracts, payment, accepted delivery and repeat behavior.

Each numeric reference is recomputed in code from the supplied values using two exact rational derivations. These arithmetic checks do not independently prove that an invented business assumption would hold in reality. Natural-language references are anchored criteria and valid alternatives, not a single required phrasing. Their application requires an actual response and external evidence-backed review.

All cases are exposed development/regression material. There are no untouched holdouts. Author controls, examples, score expectations and diagnostics belong only to the evaluator side and are not projected as executor facts.
