# [COMPANY NAME] company brief

Reusable blank template for an explicitly commissioned company effort. Fill only what is useful; link to sufficient existing 00/03/09/10 records instead of duplicating them. Blank fields are unknown, not approved or zero. This template is complete as a template and is not evidence that a company exists or operates.

| Field | Working record |
|---|---|
| Company/item, revision and as-of date | |
| Requested outcome and scope | Prepared experiment, company pack, actual delivery or operating improvement; include exclusions |
| Accountable human owner and canonical writer | [OWNER]; confirm canonical writer if different |
| Governing position and record locations | File 03 revision; 00 locations; 09 unresolved questions; 10 decisions |
| Customer, user and payer | Distinguish each; narrow initial segment and context |
| Problem and evidence | Observed behavior, source/date and limitations; distinguish founder belief |
| Offer and price | Promised outcome, unit, scope, price or test price, acceptance, delivery time and exclusions |
| Initial customer and sales route | First customer source/channel, concrete ask, owner and test metric; distinguish a proposed route from authorized outreach |
| Minimum delivery/product requirements | What must work to fulfill this bounded offer, verifiable acceptance and failure conditions; no full requirements document by default |
| Current evidence | Separate interviews, intent, bookings, signed contracts, delivery acceptance, invoices, cash receipts and repeat use; link actual evidence |
| Hardest unproven assumption | The fact or behavior that would change the next commitment |
| Next experiment and decision | Cheapest sufficient test; predeclared pass/change/stop criteria; evidence source, owner and observation horizon |
| Exposure limit | Maximum authorized cash and time, obligations/refund exposure and stop conditions |
| Delivery and failure route | Steps, owner, inputs, acceptance, support, refunds/cancellation, recovery and critical dependencies |
| Economics, cash and capacity | Model location, currency, period, as-of date, actual/estimate/assumption labels and sources; unpaid obligations, cash floor, founder hours and stress case |
| Applicable activity/jurisdiction issues | Material questions only, scoped evidence or unknown, owner, affected commitment and required review; file 05 if useful |
| Authority and reserved actions | Exact permitted writes/actions, amounts/targets/conditions, source of authorization, human decisions still needed |
| Current company readiness | Frame/Test/Deliver/Operate evidence reached; separate prepared experiment from MVC demonstrated and repetition demonstrated |
| Gate outcome and next authorized action | Proceed/Hold/Walk for the specific commitment, evidence, limits, owner and next review trigger |
| Acceptance and continuation | What the recipient can do with this result, checks actually performed, necessary saved state and remaining blockers |

Choose thresholds before observing the experiment. A new threshold requires a new or explicitly amended test. Scope current evidence to its actual subject and date. Use the source kit's `profiles/company.md` for definitions; passing a template check is not a company-readiness judgment.
