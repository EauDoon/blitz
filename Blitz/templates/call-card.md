# Call card

Prepare it before a commissioned meeting. Keep the working card to one page; select relevant prompts rather than filling every optional field.

| Field | Content |
|---|---|
| Meeting | Who, when (DD-MM-YYYY h:mm AM/PM SGT), where |
| Goals | At most three, each tied to a gate or a file 09 ID |
| Opener | First two sentences |
| Questions that settle Hold items | In order of priority, with the file 09 ID |
| What not to say | Commitments, numbers or claims to keep back |
| Time budget | Per topic |
| Capture decision | Notes by default. Record only after the owner confirms applicable permission/consent, participants, purpose and permitted reuse; log the decision. Unknown, absent or refused permission means no recording. If withdrawn, stop recording and resolve handling of the existing recording before reuse. |
| Capture handling | Named note-taker; approved storage/transfer route; authorized access group; recording/transcription service permission if used; minimum necessary content and redactions; access/retention owner and deletion/return date or trigger |
| After the call | Use authorized notes or a permitted transcript for the commissioned follow-up. The 1-hour debrief target applies to a selected measured pilot. Mark capture gaps; do not invent missing statements. |

Resolve blank handling fields before collecting or sharing capture. Recording requirements depend on the applicable context and jurisdiction; this card does not establish a universal consent rule or disclosure authority.

## Optional customer-discovery prompts

Use when the call tests a commercial assumption. Put selected questions into the existing Questions field; this is not an extra required form. See the [customer-discovery guide](../profiles/customer-discovery.md).

* **Recent episode:** When did this last happen? Walk me through what you did and what happened next.
* **Current alternative:** What do you use today, including manual work or doing nothing? What have you tried or paid for, and when?
* **Cost and consequence:** What money and staff time did that episode consume? What happens if you leave it unresolved? Record currency, period and whether each figure is reported, evidenced or estimated.
* **Buying path:** Who uses the result, pays, approves and accepts it? What budget, procurement, security or switching constraints matter for this buyer?
* **Separate offer test:** After discovery, if within the call's authority, present one bounded offer and exact price/terms. Ask for a specific next commitment and capture the response and stated reason. Use the [experiment card](experiment-card.md); do not infer that a request for a paid pilot is payment.

Capture speaker/role, source/date, important wording and gaps using the approved handling route. For an internal department, use the relevant user/sponsor, workflow, resource and acceptance questions; omit an external price test unless external sales are actually in scope.
