# Claim record

A claim is what a party says is true. It stays a claim until its evidence is read. Source ID means the actual source for the quoted/paraphrased claim; record any separate verification source IDs and exact readable passages in Evidence still needed / the supporting source record. Never attribute a fact from another source to the task briefing/context source. A plausible statement with wrong attribution fails verification and blocks only dependent reliance.

Source fidelity: use the actual evidence source, and only the current task/scenario sources for their stated subjects. If a source does not specify its subject, retain that uncertainty; never fill it from another batched scenario, prior output or memory. Name source IDs without assigning an unsupported subject.
