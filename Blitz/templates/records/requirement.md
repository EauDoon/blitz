# Requirement record

| Field | Content |
|---|---|
| Requirement ID | Prefix by area, for example SP-01 |
| Text | One testable statement |
| Priority | Must, Should, Could |
| Phase | |
| Source | Decision ID or source ID, quoted |
| Owner | |
| Acceptance test | What a reviewer runs or reads to pass it |
| Status | Proposed, adopted, built, passed, dropped |
