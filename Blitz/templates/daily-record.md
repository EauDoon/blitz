# Daily record

Use for a commissioned measured pilot or an explicitly requested useful cadence. [Operating Loop](../skills/blitz/references/operating-loop.md) creates no daily-record duty. The scribe records applicable evidence; PRIVATE when it holds private-lane content.

| Field | Content |
|---|---|
| Date | DD-MM-YYYY |
| Clock | T+[h]h at close; on track or behind by [h]h |
| Stage per workstream | From file 00 |
| Decisions | File 10 entries |
| Outputs and states | |
| Write conflicts | Any overlap between sessions, with the files and times |
| Skill loads observed | From receipts, with deduplicated load IDs |
| Active time | Hours of work done today |
| Waiting time | Hours spent waiting on a person, an access or a reply |
| Blocked time | Hours a gate or a missing input stopped work |
| Time lost and cause | Rework by reason: new decision, stale source, missing input, defect |
| Tomorrow | Top three ready tasks |
