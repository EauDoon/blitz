# Experiment card

One card tests the hardest assumption: commercial for a venture (from the GTM hypotheses), adoption or delivery for a program (from the KPI tree).

Use an adequate existing brief or record instead when it already holds these answers. Complete only applicable fields; this card creates no outreach, spending or scheduling authority.

| Field | Content |
|---|---|
| Assumption | [Who] will [do what] because [why] |
| Cheapest test | |
| Success threshold | Observable pass criterion fixed before the test runs; define the unit and denominator for numeric thresholds |
| Change and stop criteria | Predeclared observations that change the test or stop the dependent commitment |
| Deadline | DD-MM-YYYY |
| Owner, authority and exposure | Owner; exact permitted action; time/cash or resource cap; relevant dependencies |
| Decision the result changes | |
| Result | Filled after the test, with the evidence |

## Optional commercial test details

Use for a customer-discovery or price test under [Frame/Test](../profiles/company.md#evidence-gates-for-the-next-commitment). The [customer-discovery guide](../profiles/customer-discovery.md) explains the method. Link existing answers rather than duplicating them.

| Field | Content |
|---|---|
| Target segment and buying unit | Who, in what situation; user/payer/approver roles; individual or independent buying unit used for counting |
| Current alternative and cost | Existing supplier, manual work or inaction; spend, staff time and consequence; units/periods and reported/evidenced/estimated status |
| Offer revision and exact price | Outcome, scope/exclusions, acceptance and delivery time; currency, price, billing unit/period, applicable setup/tax terms, payment timing and cancellation/refund conditions |
| Requested behavior | Specific observable commitment, by whom and by when; distinguish discovery from the sales ask |
| Sample and observation window | Recruitment source, selection limits, dates; relevant counts for contacted, interviewed, shown this exact offer and observed commitments; deduplicate at the chosen buying unit |
| Response and evidence | Exact response or labeled paraphrase, date and source; separate interest, pilot requests, agreed terms, verified payment, accepted delivery, refunds and repeat use |
| Objection and next test | Stated reason versus interpretation: need, price, timing, trust, requirements, switching or procurement; supporting/contrary evidence and the next smallest useful test |

Keep different segments, offer revisions and price/term variants identifiable. Calculate rates only from known, matching numerators and denominators; an unavailable or zero denominator is not a zero conversion rate. Nonresponse has no known reason unless evidence supplies one. Preserve original criteria and results; an amended offer or criterion starts a separately identified test.

For internal departments, omit commercial fields that do not apply and use actual user behavior, sponsor authority, available resources and agreed acceptance. Budget approval is not adoption or a cash receipt.
