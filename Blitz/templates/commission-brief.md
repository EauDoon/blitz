# Commission brief

Use this brief under [the operating contract](../setup/operating-contract.md). A delegated output needs the relevant fields; single-owner lean work may keep them inline. Infer reversible defaults and ask only about material unresolved choices. The brief adds no authority or mandatory user questionnaire.

| Field | Content |
|---|---|
| Deliverable ID and name | |
| Item identity and request mode | New or existing item ID/title; build, revise, review, plan or export as authorized. Infer a reversible title for genuinely new work; clarify competing item identities before dependent work |
| Decision it supports | The recipient's intended next action or use; not every artifact requires a decision |
| Audience and confidentiality | Build lane or private lane; who may read it |
| Owner and next user | |
| Format, length and date | Requested format governs; if unspecified, the smallest usable supported format for the task. Comprehensive may select the Google Doc plus verified DOCX default; other multiple formats need a task/audience reason. Page budget for paginated artifacts |
| Governing decisions and source snapshot | File 03 version; source IDs and revisions/fingerprints; intentionally shared inputs and their permitted use |
| Required coverage | Necessary sections, tables, figures or fields for the recipient; connect each consequential requirement to its actual readable evidence and output location; retrieve authorized missing inputs before dependent production |
| Exclusions | |
| Open assumptions and permitted treatment | Each labelled; which may appear in audience-facing text |
| Dependencies | Required inputs not yet retrieved, source locations/access, extraction gaps, conflicts and decisions; hold only dependent work |
| Required skill routes | Selected methods such as doc-style, pitch-architect or cold-read; pinned Blitz/method revisions and required references, scripts, assets and actual tool capabilities |
| Acceptance criteria and checks | Recipient can do the commissioned next thing using the actual artifact; required content populated/supported, calculations and cross-file values reconciled, requested format/destination usable. Name applicable render, execution or independent-review checks. Preserve template/partial scope |
| Canonical destination and write scope | Folder or file; the files this task may write |
| Export, if commissioned | Destination, exact file allowlist, editable originals, dependency closure and receiver prerequisites/checks. Reference copy by default; authorized working-copy development records parent identity/revision and its own identity/allowed writes. Original ownership transfer requires an explicit ruling |

For missing required inputs, use [context acquisition](../skills/blitz/references/context-acquisition.md). A compact inline commission suffices; ask only for material gaps remaining after focused authorized retrieval.

Within Blitz, apply [its intent and supporting triggers](../setup/source-use.md) proportionately during active work. An exported item uses only its own scoped `PROJECT_INSTRUCTIONS.md` and included methods. Method selection preserves the requested mode and does not expand authority. Ordinary commissioned outputs use this brief and their acceptance criteria; `BUILD_PACK.md` is mandatory only for actual project skill builds.
