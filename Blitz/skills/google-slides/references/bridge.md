# Optional presentation conversion bridge

A bridge is an external prerequisite, not a service supplied or deployed by Blitz. Use one only when
the user has explicitly selected an existing authorized bridge for this task and its owner provides the
current interface, permitted data, destination and recovery contract through an approved secret channel.
Never copy bridge tokens or credentials into this package, a prompt, logs, or an exported item.

Confirm authority for the destination and upload before sending file bytes. Validate the expected
endpoint and current schema through the supported host tools. An example hostname is not an allowlist.
Do not search unrelated personal stores for a bridge configuration or choose between ambiguous accounts.

Reconcile an uncertain upload before retrying. A success response must be followed by destination
readback of file identity, presentation type and relevant slide contents. If the bridge is unavailable,
deliver the editable local presentation and report that conversion was not completed.
