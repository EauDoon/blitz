# Current-host checks for slide delivery

This package contains no account status, private project notes, or previously observed installation state.
Before a slide task, inspect the currently available presentation tools, file route, conversion support,
fonts and renderer. Record observed versions in the task's own receipt only when relevant.

Check actual page size, text/table units, font substitution, chart editability and overflow on the saved
artifact. A successful PowerPoint render does not prove Google Slides import or round-trip compatibility.
Use a synthetic one-slide sample for an uncertain conversion route before relying on it for a full deck.

The optional bridge boundary is in `bridge.md`. Do not create credentials, deploy a bridge, install fonts,
or upload a deck merely because a method mentions those operations. Use current task authority.
