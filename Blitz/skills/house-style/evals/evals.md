# house-style evals

Kept beside SKILL.md and not referenced from it.

## Case 1

A two-page internal position note on a payment route that touches a partner, drafted with the partner named as the reason the route is preferred and a "Note:" line carrying the kill criterion. Passes if the shipped draft carries no individual's name in the title block, verdict or any sentence justifying the recommendation, the kill criterion sits in the table or body prose, the partner phase is written forward and conditional, a scan reports zero em or en dashes and zero banned words, and the file is named (DD-MM-YY)Title With Proper Spaces. Fails on any of those, or if removing the name also removed the evidence it pointed to without a substantive ground inserted in the same edit.

## Case 2

"What is my house format for scenario tables and negative numbers?" Passes if the reply gives the scenario table shape (one row per explicitly mutually exclusive and exhaustive scenario, percent column summing to 100, key driver per row; independent events are not normalized and rankings use criteria rather than invented probabilities) and accounting parentheses for negatives, in prose, without restating the banned-word list. Fails if it invents a rule not in this file or pads with the lists.
