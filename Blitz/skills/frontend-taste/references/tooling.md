# Optional tooling

Neither is required. Both are useful when the environment allows an install.

* **impeccable** (impeccable.style), Node 22.12 and above. `npx impeccable install`, then `/impeccable init`. Commands: `/polish`, `/audit`, `/typeset`, `/distill`, `/live`. The CLI emits JSON suitable for a build gate. Reads context from `DESIGN.md` and `PRODUCT.md`.
* **taste-skill** (Leonxlnx/taste-skill, MIT). `npx skills add Leonxlnx/taste-skill`. Portable across Claude Code, Codex, Cursor, Gemini CLI, v0 and Lovable. Variants include `gpt-taste` (stricter, for GPT and Codex), `image-to-code`, `redesign-existing-projects`, `minimalist-ui`, `industrial-brutalist-ui`.
