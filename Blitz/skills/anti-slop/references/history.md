# Pattern-review adaptation notes

This reusable package contains no personal writing corpus, performance log, or private editorial history.
Inherited third-party sources and their unresolved license boundaries are recorded in `../NOTICE.md`.

## Live corpus

Empty by design. When a user explicitly asks to record an observation, save only the permitted example,
pattern, proposed revision, and scope in that user's authorized project records. Do not append private
writing to this reusable package or use another user's examples as a voice reference.

## Synthetic example

Before: "Our toolkit unlocks unprecedented excellence for every team."
After: "The toolkit records who owns each task and when it is due."
