Icon library

A monochrome library for IT/cloud illustrations: 50 generic Tabler icons (MIT) and 37 newly authored generic stand-ins for product nodes. Official brand artwork is not included. Several products share a functional symbol, so keep product names as text labels. See provenance and notices. Every icon uses currentColor.
